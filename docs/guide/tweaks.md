# Tweaks

**Tweaks** is a slide-out panel of dials that adjust whatever style you are
looking at, live, on every page. Open it with the **Tweaks** button in the
header, from the rail, or with <kbd>Ctrl</kbd>+<kbd>.</kbd>.

![Tweaks](/screenshots/tweaks.png)

## The dials

| Dial | Range | What it changes |
| --- | --- | --- |
| Corner radius | 0–300% | Every radius. Below 100% corners get sharper; above it radius is added, so square styles can be rounded too |
| Border width | 0–400% | Every border. Above 100% borderless styles gain an outline |
| Shadow depth | 0–200% | Offsets and blur of every shadow; 0% is flat |
| Spacing | 60–160% | Padding inside buttons, inputs and cards |
| Type size | 80–130% | Every step of the type scale |
| Accent colour | | Any colour, or the style's own. Hover shade and text on the accent are worked out for you |
| Motion speed | 0.25×–2× | The duration of every transition. This one is a preference, kept across styles |

A small specimen at the top of the panel shows the result even when the panel
covers the preview. Each dial has its own reset, and the default is marked on
the track.

## Where tweaks apply

Tweaks sit on top of the style without changing it. They apply to the main
preview, to all three frames in compare views and to the templates. The
header's style picker reads "tweaked" and the **Tweaks** button carries a dot
while any dial is away from 100%. **Copy link** in Templates carries the tweaked
style, so the person you send it to sees the same thing.

## Keep or drop

- **Save as new style** bakes the tweaks into a new custom style (for example
  "Glassmorphism (Tweaked)"), selects it and resets the dials. Edit it further
  in the [Customizer](/guide/customizer) or export it.
- **Reset** returns every dial to 100%.

The dials are remembered in this browser until you reset them.
